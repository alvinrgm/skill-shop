# Breakdown template — Phase 2 production document

The breakdown is the Hollywood-studio-style pre-production document for the spot. One table, locks visual + audio + track sources together so audio architecture cannot drift mid-production.

## Why this exists

Past mistake (a pharma-ad-parody spot): wrote `script.md` with visual + dialogue mixed in one column, never explicitly designed the audio architecture. Defaulted to Strategy A (per-clip seedance native audio) at Phase 5 because that's the cheap path. But the spot's pharma-parody structure REQUIRED Strategy B (continuous narrator). Took 3 stringouts (v1 / v2 / v3) and ~200 wasted credits to pivot.

The breakdown forces the audio architecture decision at Phase 2 when it's ~$0 to change. Adding a column for "Narrator VO (11L)" alongside "In-scene dialogue (seedance)" makes the architecture VISIBLE in the table → if rows 1, 4, 6, 7b all have 11L populated, that's a Strategy B spot and we know it upfront.

## The 8-column structure

| # | Sec | Visual | In-scene dialogue (seedance) | Narrator VO (11L) | Music + SFX | Char refs | Env refs |

**Column purposes:**

→ **#** — shot number (1, 2, 3, ..., or sub-cuts like 5a, 5b)
→ **Sec** — target duration in seconds. seedance fast mode has [4, 15] range — keep within. For VO-only ken-burns shots, no seedance minimum.
→ **Visual** — what happens on screen. Camera, characters, action, key props. One paragraph max. `<br><br>` for line breaks in cells.
→ **In-scene dialogue (seedance)** — dialogue lip-synced to on-screen characters, generated by seedance with native audio. Speaker labels in CAPS. Empty `—` if no in-scene dialogue.
→ **Narrator VO (11L)** — voice-over delivered as overlay, not lip-synced. Generated separately (your locked 11L narrator voice) and mixed in. Empty `—` if no VO.
→ **Music + SFX** — what music bed plays, ambient/SFX descriptions in parens. If music is the same continuous bed across all shots, write "continuous Suno bed (see brief)" in row 1 and "(continuous bed)" in subsequent rows.
→ **Char refs** — which character refs (hank_sheet, wife_hero, neighbor_hero) feed into this shot. Empty `—` if no characters.
→ **Env refs** — which environment refs (kitchen_sheet, cookout, office, diner) feed in.

## Forcing functions

The columns are designed to surface architecture decisions automatically:

→ **Rule 1 — hybrid audio flag:** If a row has BOTH `In-scene dialogue` AND `Narrator VO` populated → that's a hybrid shot. Plan the overlay timing now (when does the in-scene line land, when does the VO drop in). Don't defer to mix time.
→ **Rule 2 — silent + VO = ken-burns:** If a row has ONLY `Narrator VO` and no in-scene dialogue, and the visual is a static product shot or simple character beat → skip seedance entirely. Use ffmpeg ken-burns over a still + overlay the 11L VO. Saves ~17 credits per shot.
→ **Rule 3 — Strategy B detection:** If multiple rows share the same `Narrator VO` voice (e.g., the 11L narrator on rows 1, 4, 6, 7b) → that's a Strategy B spot. Generate the 11L track FIRST as one continuous gen, before any seedance gens. This locks voice consistency across the spot.
→ **Rule 4 — Strategy A detection:** If `Narrator VO` is empty across ALL rows and only `In-scene dialogue` is populated → that's Strategy A. Per-clip seedance native audio is correct. No 11L needed.
→ **Rule 5 — credit-saving audit:** Before any seedance gen fires, scan the breakdown for rows that match Rule 2 (silent + VO). Convert those to ken-burns plan. Surface savings to the operator.

```
   Used in shots: 3, 5b, 5c, 5d, 7a (in-scene only — VO is 11L)

→ NARRATOR (11L) → voice_id `<your locked narrator voice_id>`, model `eleven_v3`, settings (stability 0.35, similarity_boost 0.75, style 0.7, use_speaker_boost true)
   Used in shots: 1, 2 (partial), 2b, 4, 5a, 6 (partial), 7b
   Pharma-ad narrator carrying the through-line.

→ NEIGHBOR (seedance) → "easygoing mid-30s American male, mid-pitch, half-laughing, warm."
   Used in shots: 2 (one line only)

→ WIFE (seedance) → "warm suburban mid-40s American, mid-pitch, amused but suspicious..."
   Used in shots: 3, 6 (one line "Hank?"), 7a
```

For 11L voices, always log the voice_id. Without it, voice consistency across re-fires is lost.

**Architecture analysis (what the table makes obvious):**
→ 8 rows have the 11L narrator → Strategy B spot. Generate the narrator track FIRST.
→ 5 rows have in-scene seedance dialogue → seedance only for those.
→ 2 rows (shot 4 + shot 7b) are silent + VO only → ken-burns candidates, skip seedance, save ~34 credits.
→ Music bed is continuous → Suno track at low volume across the whole spot, overlaid in FCP.
→ Shots 2 and 6 are hybrid → plan overlay timing now (shot 2: neighbor in-scene at 1-2s, VO at 2.5-4.5s; shot 6: VO at 0.3-2s, wife at 2-3s, VO at 2.5-5s).

Locking this at Phase 2 is what lets a spot like this ship in v1 instead of v3.

## When to deviate

The breakdown is the default. Deviate only if:
→ Spot is single-shot (1 clip) and very simple → script.md alone is fine
→ Spot is a re-edit of an existing campaign with locked audio → use the prior breakdown as source-of-truth

For everything else, fill the breakdown completely at Phase 2 before any generation fires.

## Naming + storage

Save to `$ADGEN_HOME/<brand>/concepts/<slug>/breakdown.md`. The breakdown is the source of truth for Phases 3-7. Other artifacts (storyboard, character bibles, asset-lock, scene start-frames) reference back to it by shot #.
